Accuracy · Rollout · Efficiency

Comparable metrics

Every model is measured against the same targets. Switch leaderboard views to compare accuracy, long-term prediction, and compute requirements.

⌁

Overall accuracy

Root mean squared error

RMSE is the square root of the average squared difference between predicted and reference values across evaluated fields and snapshots. Lower values indicate closer predictions.

⇄

Scale-aware accuracy

Relative L2

Relative L2 compares the prediction error with the reference field magnitude. It helps compare errors across variables and benchmark scales.

◷

Long-term behavior

Rollout error

Track error at multiple points in the prediction horizon. A model that stays accurate later in the rollout may behave differently from one that leads on a single-step score.

◈

Resource use

Efficiency

Compare parameter count, training time, inference time, and memory alongside accuracy to understand the compute tradeoffs.

▤

Field-level view

Per-variable error

Inspect velocity and pressure errors independently. This view makes it easier to see whether a model performs differently across predicted quantities.

✓

Common comparison

Shared evaluation map

Graph and Matrix predictions are compared over the benchmark’s dataset mesh so scores remain consistent across model representations.
